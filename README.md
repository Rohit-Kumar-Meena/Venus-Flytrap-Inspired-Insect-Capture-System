# Venus Flytrap–Inspired Insect Capture System

An automated, chemical-free insect trapping system inspired by the natural mechanism of the Venus flytrap. The system uses ultrasonic sensing, servo actuation, and fan-based suction to capture both flying and crawling insects.

## ⚙️ Key Features

- Automated detection using ultrasonic sensors
- Separate traps for flying and crawling insects
- Servo-driven trap mechanisms
- Fan-based suction for insect capture
- Replaceable collection box for hygienic handling
- Arduino-based control with MOSFET-driven fan switching
- Telescopic height adjustment for different crop heights

## 🔧 Components

- Arduino Uno
- Ultrasonic Sensors
- Servo Motors
- DC Fans
- MOSFETs
- Stepper Motor

- Limit Switch
- Collection Box
